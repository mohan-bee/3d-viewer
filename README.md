# Gimbal export unit snapshots

Actual Gimbal One 0.2.0 P02_UpperJaw, designed width 128 mm. Images render real before/after exports, with measured physical dimensions under the glTF metre unit convention. Each view is independently framed for visibility. These are diagnostic snapshots, not Blender screenshots.

Viewer: real MixedStlModel and Download GLTF hook. Native: converter default millimetres and explicit outputUnits m. The comparison reports record the measurements, source preservation, repeated-download result and native buffer equality. Images are hosted on this evidence branch and are not part of the fix PR diffs.
